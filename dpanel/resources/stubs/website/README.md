# Website starter files

This directory was prepared by dPanel.

## Included files

- `index.php` — the temporary starter page. Replace it with your application.
- `assets/favicon.ico` — a local favicon that does not depend on the panel domain.
- `assets/bootstrap-icons/bootstrap-icons.min.css` — local Bootstrap Icons stylesheet.
- `assets/bootstrap-icons/fonts/` — local Bootstrap Icons webfonts.

All asset links in the starter page are relative to this website, so they work on HTTP, HTTPS, custom domains, and subdomains without contacting `dpanel.localhost`.
